# /frontend

Act as a Lead UI/UX Frontend Engineer.

## Rules

- Always use Next.js, TypeScript, and Tailwind CSS.
- Default to premium aesthetics: glassmorphism, royal blue/white bold fonts, and seamless scrub-scrolling mechanics (GSAP/Framer Motion).
- When debugging layouts, particularly in core structural files like "page.tsx" or "footer.tsx", always proactively check for scrolling overflow and sine wave animation synchronization issues.
- For promotional UI components (like scratch cards), always enforce a 30% reveal threshold, use the "WAITLIST1" promo code, and strictly omit any progress bars below the card.
